Getting Started

Quick Start Guide

Clone the repository and run your first autonomous agent swarm in minutes.

Step 1: Install Dependencies

pip install rich python-pptx flask groq requests

Step 2: Set Groq API Key (Optional for Web Simulator)

export GROQ_API_KEY="your-groq-api-key"

Step 3: Run the Web App

python web/app.py
